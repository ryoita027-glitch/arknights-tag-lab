# RECRUIT / TAG LAB — アークナイツ公開求人タグ検索

日本版アークナイツの公開求人に対応した、スマートフォン向けの非公式タグ検索ツールです。**2026年10月15日現在・158人・29タグ**に対応（2026年10月14日追加のパラス・GALLUS²を含む）。

## サイトURL

https://ryoita027-glitch.github.io/arknights-tag-lab/

**GitHub Pagesの設定が完了していない場合、URLは開きません。**
`Settings → Pages → Deploy from a branch → main → / (root) → Save` を設定してください。

## 使い方

1. 公開求人画面に出た最大5つのタグをタップして入力（職業タイプの正式名称検索にも対応）。
2. 1〜3タグの組み合わせを自動比較し、★6・★5・★4以上確定を上位に表示。
3. 9:00で通常募集。ロボット狙いは3:50に切り替え。
4. iPhoneではSafariから「ホーム画面に追加」。キャッシュに成功した後、オフラインでの利用が可能な設計。

**重要：**「確定」は選択タグが求人完了まで消去されなかった場合の最低レアリティです。タグは消えることがあるため、確実な入手を保証しません。

- `index.html`: アプリ画面・全158人のデータ・検索ロジック（外部API不要）
- `sw.js`: オフラインキャッシュ
- `manifest.webmanifest`: ホーム画面追加用マニフェスト
- `icon-192.png`, `icon-512.png`: アプリアイコン
- `AUDIT_2026-10-15.md`: [2026年10月15日のデータ再監査記録](AUDIT_2026-10-15.md)
- `tests/recruitment-audit.cjs`: 全8,178条件の回帰テスト
- `PUBLISH_GUIDE.md`: 公開手順

テスト（Node.jsが必要）：

```bash
node tests/recruitment-audit.cjs index.html
```
