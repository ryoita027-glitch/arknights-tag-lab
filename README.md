# RECRUIT / TAG LAB — アークナイツ公開求人タグ検索

2026年10月14日追加分（パラス・GALLUS²）を含む、日本版公開求人のオペレーター **158人** を収録。個人用・非公式のタグ検索ツールです。**AI・外部API・通信による検索処理は不要です**。

## ファイル

- `standalone.html`：**1ファイルだけで動作**。PCなどでそのまま開く場合はこちら。すべてのCSS・JavaScript・オペレーターデータを含みます。
- `index.html` + `manifest.webmanifest` + `sw.js` + `icon-*.png`：スマートフォン向けPWA版。Webサイトとして**HTTPS**で公開すれば、Safari / Chrome のホーム画面に追加して、初回接続以降はオフライン起動できます。
- `app.js`、`style.css`、`template.html`、`operators.tsv`、`build.py`：修正・更新用のソース。`python build.py`でHTMLを生成します。

> iPhoneでは「ファイル」アプリ内のHTMLプレビューはJavaScriptが正常動作しないことがあります。iPhoneで確実に使うには、**PWA一式をGitHub PagesなどのHTTPSサイトに配置し、Safariからホーム画面に追加**してください。PWAのオフライン対応は**初回オンライン起動およびファイルのキャッシュ完了後**に有効です。アプリをiPhoneに直接インストールするためのiOSネイティブ版ではありません。

## 使い方

1. ゲームの公開求人画面に出てきたタグを、画面左側で **最大5つ** タップ。
2. 右側に 無駄なタグを除いた1〜3タグの組み合わせが高レア確定順に表示されます。**9:00** が基本。
3. 「★4以上確定だけ」で候補を絞れます。必要なら「すべて表示」で省略した組み合わせも確認できます。結果を開くと、排出候補のオペレーターを全員確認できます。
4. 「ロボット」を狙う場合は **3:50** に切り替えます。
5. 「キャラクターから逆引き」では、オペレーター名からタグを確認し、検索にセットできます。

選択タグと設定時間は端末内に保存されます（ブラウザが保存を許可した場合）。画面幅375px程度のスマートフォンに対応し、外部スクリプトやフォントは読み込みません。

## 判定の重要な注意

- 9時間の一般募集は★3〜★5が対象。★6は「上級エリート」を選んだ場合のみ対象、「エリート」は★5が対象となります。
- 3:50では★1〜★4が候補になり、★5・★6は候補に入りません。
- 複数タグはすべてを満たすオペレーターとの**AND条件**です。不可能な組み合わせは除外します。
- **「確定」は選んだタグが最後まで消えなかった場合の、オペレーター候補の最低レア度**を示します。タグ消去・排出率などの実確率は分かりません。該当オペレーターが一人でも、排出される確率100%という意味ではありません。
- 「ロボット」は3:50以下を利用します。星1ロボットが対象になっていることとロボット入手そのものが必ず成功することは別です。
- 今後の公開求人追加・仕様変更があった場合、更新が必要です。**2026-10-14**を基準にしています。

## v2更新点

- タグを増やしても出現候補が全く変わらない「無駄な組み合わせ」は標準表示から自動除外。すべて表示で再確認できます。
- ★4以上確定（ロボットモードでは★1ロボット）だけを表示する切り替えを追加。
